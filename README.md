# Frames ToC

A lightweight Miro Web SDK app that creates a table of contents from selected frames.

## Usage

1. Select one or more frames on your Miro board
2. Click the app icon in the toolbar
3. An ordered list of hyperlinks to frames will be created as a text oject on the board

## Development

Install dependencies:
```bash
npm install
```

Start the local dev server:
```bash
npm start
```

The app runs at `http://localhost:4173`. Set this as your app URL in the [Miro Developer Hub](https://developers.miro.com).

## Requirements

- Node.js >= 20.9.0
- A Miro account with an app configured in the Developer Hub
